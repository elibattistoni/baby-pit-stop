# Baby Pit Stop

A community-driven map app that helps parents quickly find places suitable for diaper changes, breastfeeding, and short baby-care stops.

## Status

Pre-development. Planning complete; scaffolding next.

## Vision

Reduce the stress of being out of the house with a baby by surfacing reliable, community-verified information about where you can change a nappy, feed a child, or take a quiet break.

## Tech stack (Stage 1 — PWA)

- **Frontend:** Next.js 15 + TypeScript + Tailwind + shadcn/ui
- **Map:** MapLibre GL JS + OpenStreetMap tiles
- **Backend:** Firebase (Auth, Firestore, Cloud Storage, Cloud Functions)
- **Hosting:** Vercel (or Firebase Hosting)

## Roadmap

| Stage | Client | Map | Trigger |
|---|---|---|---|
| 1 | Next.js PWA | MapLibre + OSM | MVP / validate |
| 2 | React Native (Expo) | Mapbox | 100+ engaged users want a "real" app |
| 3 | Native Android (Kotlin + Compose) | Google Maps | 50k+ MAU |
